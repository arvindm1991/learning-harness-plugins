# Learning Harness

Your agent gets better. You should too.

A local learning companion alongside your coding agent. It notices useful ideas in the work, offers questions and visual explanations, and keeps learner memory on your device. Learning requests use your existing host model connection and additional tokens from your allowance.

[Website](https://learningharness.dev) · [Documentation](https://learningharness.dev/docs/) · [Releases](https://github.com/dontdumb/learning-harness-plugins/releases)

## Downloads

This is the public **distribution repository**, not the development source repository. Accepted plugin packages will appear under Releases, alongside setup instructions, release notes and SHA-256 checksums.

No package has been promoted into this repository yet. Do not treat this repository as an installable plugin marketplace or invent an npm package name. Each release will state the hosts and versions actually tested. Claude native sidebar support is still under validation.

## What is included

A release contains the files needed to run the local plugin: a host manifest, launcher, bundled runtime, prompts and UI, plus required notices. It excludes development history, internal evaluations and personal learner data. The default GitHub Source code archives contain this distribution repository's documentation; they are not plugin installers.

Local code is inspectable. Public availability does not imply an open-source license. See the terms and third-party notices shipped with each package.

## Privacy and control

There is no Learning Harness backend receiving your code, prompts or learner answers. Selected work and learner context go through your existing host's model connection. Learning consumes additional allowance; memory stays local. Optional anonymous usage metadata is separate and can be disabled. Check the [privacy documentation](https://learningharness.dev/docs/privacy/) for the data flow.

## Feedback

Open an issue with your host version, plugin version, steps and a redacted screenshot. Do not post private code, learner memory, prompts, credentials or raw diagnostic logs.
